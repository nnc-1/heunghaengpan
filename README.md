# 흥행판 (Tauri 시험판 · v개발.000008)

크랙(Wrtn)에 올린 **내 작품**의 대화수·좋아요·댓글·대화방 수를 스냅샷으로 모아 증가량과 추이를 보는 앱입니다.
단독 exe 하나로 동작하고, 기록은 exe 옆의 `흥행판_스냅샷` 폴더에 파일로 쌓입니다 (폴더째 옮기면 기록도 같이 가요).

> 넉넉한 취향이 클로드와 함께 만들었어요.

## 쓰는 법
1. `흥행판.exe` 실행 (윈도우 10/11, 내장 웹뷰 WebView2 필요 — 윈도우 11은 기본 설치됨)
2. **크랙 페이지 열기** → 앱 안에 열린 크랙 페이지에서 직접 로그인한 뒤 그 창을 닫기 (비밀번호는 앱이 다루지 않아요). 로그아웃도 그 페이지에서 해요. 로그인 상태는 버튼 옆에 표시돼요
3. **스냅샷 받기** → 내 작품 통계를 받아 화면에 넣고 폴더에도 저장
4. 앱을 다시 켜면 폴더의 기록을 자동으로 읽어요

## 기록 폴더 (exe 옆 `흥행판_스냅샷`)
- exe 옆에 쓸 수 없는 위치(예: Program Files)면 `문서\흥행판_스냅샷`을 대신 써요
- 처음 만들어질 때 예전 위치(`문서\흥행판_스냅샷`)의 기록 파일을 복사해 와요 (원본은 그대로 남아요)
- `앱 로그인 정보 지우기`: 앱 안 크랙 창의 로그인(크랙·구글 등)과 캐시를 지워요. 공용 PC에서 쓴 뒤에 눌러 주세요. 스냅샷과 장부는 그대로예요
- 작품 옆 `크랙에서 보기`는 앱 안의 크랙 창에서 열려요 (로그인 상태 공유)
- `흥행판_스냅샷_YYYY-MM-DD_HH-mm.json` : 스냅샷 한 번에 파일 하나
- 화면에서 기록을 삭제하면 파일은 `삭제됨` 폴더로 옮겨져요 (완전히 지워지지 않음)
- 전체 기록 묶음 파일을 넣으면 하나씩 풀어서 저장하고 원본은 `가져옴` 폴더로 옮겨요
- 파일을 끌어다 놓거나 눌러서 올린 기록도 자동으로 이 폴더에 저장돼요
- 전체 기록 내보내기는 `내보내기` 폴더에 저장돼요
- `흥행판_수익장부.json`: 스냅샷 사이 기간별 추정 수익을 이어서 쌓는 장부예요. 스냅샷을 지워도 장부는 남아요 (목록의 스냅샷으로는 읽지 않아요)

## 만들기 (개발자용)
```
npm install
npm run sync     # (개발용) 옆 폴더 '흥행판'의 최신 뷰어를 viewer/ 로 가져오기
npm run build    # 단독 exe: src-tauri/target/release/heunghaengpan.exe
```
- 화면은 `viewer/흥행판_보기.html` 을 그대로 쓰고, 앱 기능은 `src-tauri/src/bridge.js` 가 덧붙여요.
- `build.yml.옮기기` 를 `.github/workflows/build.yml` 로 옮기면 GitHub Actions가 윈도우 exe를 빌드해요.
- 자체 검사: 환경변수 `HEUNG_SELFTEST_OUT=파일경로` 로 실행하면 폴더 읽기/저장/삭제 동작을 확인하고 결과를 적은 뒤 종료해요.
